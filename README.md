# V3.1 표본보호 보완

- 현재상황 표본 1~7회: **긍정 상황보너스 0%**
- 8~15회: 상황 성적을 단계적으로 부분 반영
- 16회 이상: 상황 성적 100% 반영
- 기존 상황별 고정 bias는 8회 미만 완전 OFF, 20회까지 단계적으로 반영
- 현재상황이 2/2, 3/3처럼 100%여도 작은 표본만으로 엔진 가중치가 튀지 않음
- 나쁜 상황 성적도 1~3회만으로 과도한 벌점을 주지 않음
- 전체/최근 성적과 현재상황 성적의 증거량을 분리해서 계산
- 최종 엔진 가중치 범위도 0.15~2.20으로 제한해 과신 억제
- 엔진 화면에 `표본부족 · 상황보너스 0%` / `부분반영` / `충분표본` 표시

# 보글사다리3 삼치기 Hedge V3 · 4확률 경쟁 독립판

- V1 / V2와 동시에 설치되는 완전 별도 앱
- 패키지: `com.bubbleladder.triplehedgev3`
- 4개 조합의 상대 발생점수를 직접 경쟁시켜 최저 1개만 제외
- 상황별 Hedge: 안정 / 급변 / 연속 / 쏠림 구간별 엔진 제외성공률을 별도 학습
- 제외실패 중심 가중치: 75% 기준보다 낮은 엔진, 특히 최근/동일상황 실패에 더 큰 벌점
- 통계 / 패턴 / 상태 계열 중복 억제 후 메타 결합
- 유사상황 검색은 표본이 충분할 때만 10~18% 보조반영
- 제외 1·2위 격차별 성공률 자동검증: 0~5 / 5~10 / 10~15 / 15+
- 상황별 성공률 및 강/보통/약 등급별 성공률 표시
- 같은 데이터 구간에서 V1 방식 / V2 방식 / V3 방식 순차검증 비교
- 미래 결과를 보지 않는 순차 재현검증
- 3분 추첨 카운트다운
- 백그라운드 자동조회 / 자동채점 / 다음 V3 계산
- 추첨 직후 API 반영이 늦으면 12초 간격 최대 3회 재확인
- 기본 배팅 1개당 최소 5,000원
- V3 자체 JSON 백업/복원
- V1/V2 JSON 백업에서 과거 결과 데이터 가져오기 지원
